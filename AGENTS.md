# Правила работы с кодом

Применяй эти правила в quest-platform. Описание механик и команды запуска находятся в [README.md](README.md).

## TypeScript и React

- Используй отступы в четыре пробела. Форматируй код существующей конфигурацией Prettier и проверяй ESLint.
- Оформляй каждый `if` многострочным блоком с фигурными скобками, даже для одного `return`.
- Внутри функций объявляй обработчики и локальные функции через `const handleAction = () => { ... }`. Передавай в JSX именованные обработчики.
- Описывай пропсы компонента отдельным интерфейсом `ComponentProps` в том же файле непосредственно перед функцией компонента.
- Для React-обработчика отправки формы используй `SubmitEvent<HTMLFormElement>`.
- Давай имя промежуточной сущности, когда оно добавляет смысл. Используй уже названное условие напрямую.

## Структура клиента

- Один React-компонент на файл. У компонента, страницы и кастомного хука своя папка. Страницы размещай в `src/client/pages`, общие простые компоненты — в `src/client/components`, хуки — в `src/client/hooks`, чистые вспомогательные функции — в `src/client/utils`.
- Дели крупный компонент на самостоятельные части по их роли. Обёртки должны добавлять поведение или структуру. Разделяй UI и контейнер там, где контейнер подключает запросы или другую инфраструктуру.
- Держи CSS рядом с компонентом. Стили элемента без собственного компонента оставляй у владельца. В блоках с BEM размещай компоненты элементов в `components/__element/`, а локальные утилиты — в `utils/`. Если блок уже использует `cn`, создавай имена классов через утилиту с коротким именем блока.
- Используй существующие оболочки страниц и общие UI-компоненты. Кратко комментируй неочевидную архитектурную обёртку рядом с её применением.

## Данные и проверки

- Храни серверные данные в TanStack Query и инвалидируй затронутые запросы после мутаций. Общие данные клиента передавай через React Context и читай контекст в нужном вложенном компоненте. Черновики и состояние формы держи локально.
- Добавляй пользовательские строки админки в русский словарь React Intl. Проект использует локаль `ru`.
- Для тестирования чистых функций используй юнит-тесты Vitest.
